
# Bmarket

Aplikasi marketplace Android untuk berbagai kategori produk.

## Teknologi
- Flutter
- Dart
- Supabase

## Fitur yang direncanakan
- Login dan pendaftaran
- Kategori produk
- Pencarian produk
- Keranjang belanja
- Toko penjual
- Pemesanan
- Dashboard admin

## Status
Tahap awal pengembangan Bmarket.
